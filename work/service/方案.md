# 野猪检测 HTTP 服务 · 方案文档

> 版本：v1.1  
> 最后更新：2026-07-27

---

## 一、概述

在 CentOS 服务器上部署野猪检测 HTTP 服务，接受同一台机器上其他服务的图像，调用 YOLOv8 模型进行目标检测，返回检测结果。

---

## 二、项目结构

```
work/service/
├── app.py                 # Flask 主应用，HTTP 路由
├── detector.py            # 模型封装（加载、预热、推理）
├── config.py              # 配置项（端口、模型路径、阈值等）
├── requirements.txt       # CentOS 部署依赖
├── boar_detection.service # systemd 服务单元（开机自启）
└── README.md              # 部署说明
```

## 三、HTTP 接口协议

### 3.1 POST /detect — 目标检测（multipart 方式）

适用于需要附带额外参数（如摄像头 ID、时间戳等）的调用方。

**请求格式：** `multipart/form-data`（标准 HTTP 文件上传）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `image` | file | 是 | JPEG/PNG/BMP 图片，**必须为 640×640 像素** |

**完整请求报文：**
```http
POST /detect HTTP/1.1
Host: localhost:5000
Content-Type: multipart/form-data; boundary=----Boundary7MA4YWxk

------Boundary7MA4YWxk
Content-Disposition: form-data; name="image"; filename="capture.jpg"
Content-Type: image/jpeg

<640×640 图片的二进制数据>
------Boundary7MA4YWxk--
```

**调用方代码示例：**
```python
import requests

resp = requests.post(
    "http://localhost:5000/detect",
    files={"image": open("capture_640.jpg", "rb")}
)
```

---

### 3.2 POST /detect/raw — 目标检测（纯二进制方式）

适用于监控平台等直接从内存获取图片、无需额外参数的调用方。

**请求格式：** HTTP body 直接放图片二进制数据，没有包装

| 请求头 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `image/jpeg` / `image/png` / `image/bmp` | 告知服务端图片格式 |

**完整请求报文：**
```http
POST /detect/raw HTTP/1.1
Host: localhost:5000
Content-Type: image/jpeg

<640×640 图片的二进制数据，直接放在 body 中，无任何包装>
```

**调用方代码示例：**
```python
import requests

# 从摄像头 SDK 直接拿到图片 bytes
image_data = camera_sdk.get_frame()  # bytes, 640×640 JPEG

resp = requests.post(
    "http://localhost:5000/detect/raw",
    data=image_data,
    headers={"Content-Type": "image/jpeg"}
)
```

**两种接口的响应格式完全一致**，见下文。

---

### 3.3 响应格式（两个接口共用）

**成功响应（HTTP 200）：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "detections": [
      {
        "class": "boar",
        "class_id": 0,
        "confidence": 0.934,
        "bbox": {
          "x1": 0.10,
          "y1": 0.20,
          "x2": 0.50,
          "y2": 0.60
        }
      }
    ],
    "image_width": 640,
    "image_height": 640,
    "inference_time_ms": 95.3
  }
}
```

**坐标还原公式：**
```
像素_x1 = bbox.x1 × 640    像素_y1 = bbox.y1 × 640
像素_x2 = bbox.x2 × 640    像素_y2 = bbox.y2 × 640
```

**未检测到目标：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "detections": [],
    "image_width": 640,
    "image_height": 640,
    "inference_time_ms": 95.3
  }
}
```

**错误响应（同样 HTTP 200，业务码区分）：**
```json
{
  "code": 40004,
  "message": "图片尺寸必须是 640×640，实际为 1920×1080",
  "data": null
}
```

### 3.4 GET /health — 健康检查

```json
{
  "status": "ok",
  "model_loaded": true,
  "model": "yolov8n_merged_final",
  "device": "cpu",
  "uptime_seconds": 3600
}
```

---

### 3.5 错误码

| code | 含义 |
|------|------|
| 0 | 成功 |
| 40001 | 不支持的图片格式（仅 jpg/png/bmp） |
| 40004 | 图片尺寸不是 640×640 |
| 50001 | 模型推理异常 |
| 50002 | 服务器内部错误 |

> 所有响应统一走 HTTP 200，调用方通过 `code` 判断业务状态。

### 3.4 超时

调用方设置 **30 秒** 请求超时即可。

## 四、技术方案

### 4.1 技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| Web 框架 | **Flask 3.x** | 已安装，轻量够用 |
| 推理引擎 | Ultralytics YOLO 8.4.19 | 已安装 |
| 模型 | `yolov8n_merged_final/best.pt` (6MB) | mAP50=0.934，单类 boar |
| 推理设备 | CPU（默认）/ GPU（可选） | 自动检测 |
| 输入尺寸 | **640×640（固定）** | 调用方自行缩放 |

### 4.2 服务处理流程

```
请求到达 → 校验图片格式 → 校验尺寸(640×640) → 模型推理 → 解析结果 → 返回 JSON
```

- 模型启动时加载一次，常驻内存
- 启动后执行一次 dummy 推理预热
- 每次请求记录耗时日志

### 4.3 CPU 推理性能

实测 **~100ms / 张**，单线程约 10 QPS。

## 五、CentOS 部署

```bash
# 1. 安装系统依赖
sudo yum install -y python3 python3-pip

# 2. 安装 Python 包
pip3 install flask ultralytics pillow

# 3. 部署
sudo mkdir -p /opt/boar-detection
sudo cp -r work/service/* /opt/boar-detection/
sudo cp work/runs/detect/boar_detection/yolov8n_merged_final/weights/best.pt /opt/boar-detection/

# 4. 开发测试
cd /opt/boar-detection && python3 app.py

# 5. 生产（systemd 开机自启）
sudo cp /opt/boar-detection/boar_detection.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now boar_detection

# 6. 验证
curl http://localhost:5000/health
curl -X POST -F "image=@test_640.jpg" http://localhost:5000/detect
curl -X POST -H "Content-Type: image/jpeg" --data-binary @test_640.jpg http://localhost:5000/detect/raw
```
