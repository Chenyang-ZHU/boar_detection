# 公网接口测试方法

> 服务地址：`https://stopper-trimmer-tavern.ngrok-free.dev`（该账号绑定的固定域名，长期有效）

---

## 部署拓扑（2026-08 起）

```
公网客户端
   │  https
   ▼
ngrok 边缘节点（亚太 region=ap）
   │
ngrok agent ──▶ 192.168.1.55:5000  （Jetson，系统服务）
```

- **Jetson**（192.168.1.55，Ubuntu 22.04 / aarch64 / JetPack 6.2）上运行两个 systemd 服务，均开机自启：
  - `boar_detection.service` — 野猪检测服务（venv python app.py，监听 5000，CUDA 推理）
  - `ngrok.service` — 公网隧道（`ngrok http 127.0.0.1:5000 --region=ap`）
- 隧道地址为此账号固定域名，重启不变化
- 注意：ngrok **必须用 `--region=ap`**，默认 us 节点从国内访问会频繁断线（ERR_NGROK_3004/3200）

## 二、目标检测

### 方式一：multipart（推荐）

调用方传入图片文件，适合大多数语言的标准 HTTP 文件上传方式。

**curl：**

```bash
curl -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect \
  -F "image=@图片路径.jpg"
```

**Python：**

```python
import requests

url = "https://stopper-trimmer-tavern.ngrok-free.dev/detect"
resp = requests.post(url, files={"image": open("图片路径.jpg", "rb")})
print(resp.json())
```

**Java（OkHttp）：**

```java
OkHttpClient client = new OkHttpClient();
RequestBody body = new MultipartBody.Builder()
    .setType(MultipartBody.FORM)
    .addFormDataPart("image", "capture.jpg",
        RequestBody.create(MediaType.parse("image/jpeg"), new File("图片路径.jpg")))
    .build();
Request request = new Request.Builder()
    .url("https://stopper-trimmer-tavern.ngrok-free.dev/detect")
    .post(body)
    .build();
Response resp = client.newCall(request).execute();
```

**C#：**

```csharp
using var httpClient = new HttpClient();
using var formData = new MultipartFormDataContent();
var imageContent = new ByteArrayContent(File.ReadAllBytes("图片路径.jpg"));
imageContent.Headers.ContentType = new MediaTypeHeaderValue("image/jpeg");
formData.Add(imageContent, "image", "capture.jpg");
var resp = await httpClient.PostAsync("https://stopper-trimmer-tavern.ngrok-free.dev/detect", formData);
var json = await resp.Content.ReadAsStringAsync();
```

### 方式二：纯二进制（raw）

适用于从内存直接获取图片的场景，如摄像头抓拍。图片数据直接放在 HTTP body 中发送，写法最简单。

**curl：**

```bash
curl -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect/raw \
  -H "Content-Type: image/jpeg" \
  --data-binary @图片路径.jpg
```

**Python（从摄像头内存数据直接发）：**

```python
import requests

# 假设这是从摄像头 SDK 拿到的图片 bytes
image_data = camera_sdk.get_frame()  # bytes

resp = requests.post(
    "https://stopper-trimmer-tavern.ngrok-free.dev/detect/raw",
    data=image_data,
    headers={"Content-Type": "image/jpeg"}
)
print(resp.json())
```

**Python（从文件发）：**

```python
import requests

with open("图片路径.jpg", "rb") as f:
    image_data = f.read()

resp = requests.post(
    "https://stopper-trimmer-tavern.ngrok-free.dev/detect/raw",
    data=image_data,
    headers={"Content-Type": "image/jpeg"}
)
print(resp.json())
```

**Node.js：**

```javascript
const fs = require('fs');
const http = require('http');

const imageBuffer = fs.readFileSync('图片路径.jpg');
const options = {
  hostname: 'stopper-trimmer-tavern.ngrok-free.dev',
  path: '/detect/raw',
  method: 'POST',
  headers: {
    'Content-Type': 'image/jpeg',
    'Content-Length': imageBuffer.length
  }
};
const req = http.request(options, res => {
  let data = '';
  res.on('data', chunk => data += chunk);
  res.on('end', () => console.log(JSON.parse(data)));
});
req.write(imageBuffer);
req.end();
```

## 四、错误响应及处理

所有错误都通过 HTTP 200 返回，以 `code` 字段区分：

| code | 含义 | 处理方法 |
|------|------|---------|
| `40001` | 图片格式不支持或图片过大 | 确保图片为 JPEG/PNG/BMP，长边不超过 1080px |
| `50001` | 模型推理异常 | 稍后重试 |

错误响应示例：

```json
{
  "code": 40001,
  "message": "图片尺寸过大（4608×2592），长边不能超过 1080px",
  "data": null
}
```

## 五、快速验证脚本

在测试机上新建 `test_boar_public.py`：

```python
"""公网接口快速验证脚本"""
import requests

BASE_URL = "https://stopper-trimmer-tavern.ngrok-free.dev"
IMAGE_PATH = "test.jpg"  # 替换为你的 640x640 图片路径


def test_health():
    resp = requests.get(f"{BASE_URL}/health")
    data = resp.json()
    print(f"[健康检查] status={data['status']}, device={data['device']}")
    return data['status'] == 'ok'


def test_detect_multipart():
    with open(IMAGE_PATH, "rb") as f:
        resp = requests.post(f"{BASE_URL}/detect", files={"image": f})
    data = resp.json()
    count = len(data['data']['detections'])
    print(f"[multipart] 检测到 {count} 个目标, 耗时 {data['data']['inference_time_ms']}ms")
    return data['code'] == 0


def test_detect_raw():
    with open(IMAGE_PATH, "rb") as f:
        resp = requests.post(
            f"{BASE_URL}/detect/raw",
            data=f.read(),
            headers={"Content-Type": "image/jpeg"}
        )
    data = resp.json()
    count = len(data['data']['detections'])
    print(f"[raw] 检测到 {count} 个目标, 耗时 {data['data']['inference_time_ms']}ms")
    return data['code'] == 0


if __name__ == "__main__":
    print("=" * 40)
    print("野猪检测服务 · 公网接口测试")
    print("=" * 40)

    if not test_health():
        print("❌ 服务不可达")
        exit(1)
    print("✅ 服务可达")

    if test_detect_multipart():
        print("✅ multipart 接口正常")
    else:
        print("❌ multipart 接口异常")

    if test_detect_raw():
        print("✅ raw 接口正常")
    else:
        print("❌ raw 接口异常")
```

运行：

```bash
python3 test_boar_public.py
```
