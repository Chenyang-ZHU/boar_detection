# 公网接口测试方法

> 服务地址：`https://stopper-trimmer-tavern.ngrok-free.dev`（该账号绑定的固定域名，长期有效）

---

## 部署拓扑（2026-08 起）

```
公网客户端
   │  https
   ▼
ngrok 边缘节点（亚太 region=ap）
   │
ngrok agent ──▶ 192.168.1.55:5000  （Jetson，系统服务）
```

- **Jetson**（192.168.1.55，Ubuntu 22.04 / aarch64 / JetPack 6.2）上运行两个 systemd 服务，均开机自启：
  - `boar_detection.service` — 野猪检测服务（venv python app.py，监听 5000，CUDA 推理）
  - `ngrok.service` — 公网隧道（`ngrok http 127.0.0.1:5000 --region=ap`）
- 隧道地址为此账号固定域名，重启不变化
- 注意：ngrok **必须用 `--region=ap`**，默认 us 节点从国内访问会频繁断线（ERR_NGROK_3004/3200）

### ⚠️ ngrok 免费版使用限制（务必注意）

ngrok 免费版**对单次请求大小没有限制**（图片/视频随便传），但卡在**月度总量**，超限后连接会失败：

| 限制项 | 免费版额度 |
|--------|-----------|
| **月度带宽（最关键）** | **1 GB / 月** |
| HTTP 请求数 | 20,000 / 月 |
| 请求速率 | 4,000 次 / 分 |
| 在线端点 | 最多 3 个 |

**使用建议：**
- ✅ 公网**只用于测试验证**：传小图（几 MB）、短视频完全没问题
- ⚠️ **别用公网传大视频/大批量数据**：一次 500MB 视频上传就消耗掉月度额度一半；累计超 1GB 后连接直接失败
- 💡 大批量、大体积的检测走**局域网直连** `http://192.168.1.55:5000`（不限流量、更快）

> 补充：ngrok 免费版在**浏览器**里访问会弹"免费版提示页"，但 curl / Python 等**非浏览器客户端不受影响**。

## 接口一览

| 接口 | 方法 | 请求 | 成功响应 |
|------|------|------|---------|
| `/health` | GET | 无 | JSON 健康状态 |
| `/detect` | POST | multipart，字段 `image` | **画框 JPEG 图片** |
| `/detect/raw` | POST | 纯二进制，`Content-Type: image/*` | **画框 JPEG 图片** |
| `/detect/video` | POST | multipart，字段 `video` | **画框 MP4 视频** |

> 图像接口返回的是**画好检测框的图片**（不再是 JSON 坐标）。错误时返回 HTTP 4xx/5xx + JSON。

## 二、图像检测

返回**画了检测框的 JPEG 图片**。支持 JPEG/PNG/BMP，**接受任意尺寸、按原尺寸返回**（长边 > 8192px 或 > 50MB 返回说明）。

### 方式一：multipart

**curl（保存结果到 /tmp/out.jpg）：**

```bash
curl -s -o /tmp/out.jpg -w "HTTP %{http_code} | %{content_type} | %{size_download} bytes\n" \
  -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect \
  -F "image=@图片路径.jpg"
```

**Python（保存到文件）：**

```python
import requests

url = "https://stopper-trimmer-tavern.ngrok-free.dev/detect"
resp = requests.post(url, files={"image": open("图片路径.jpg", "rb")})
if resp.status_code == 200:
    with open("result.jpg", "wb") as f:
        f.write(resp.content)   # resp.content 是画框图片字节
    print("已保存 result.jpg")
else:
    print(resp.json())          # 错误是 JSON
```

**Java（OkHttp）：**

```java
OkHttpClient client = new OkHttpClient();
RequestBody body = new MultipartBody.Builder()
    .setType(MultipartBody.FORM)
    .addFormDataPart("image", "capture.jpg",
        RequestBody.create(MediaType.parse("image/jpeg"), new File("图片路径.jpg")))
    .build();
Request request = new Request.Builder()
    .url("https://stopper-trimmer-tavern.ngrok-free.dev/detect")
    .post(body)
    .build();
try (Response resp = client.newCall(request).execute()) {
    if (resp.isSuccessful()) {
        byte[] img = resp.body().bytes();   // 画框图片字节
    }
}
```

**C#：**

```csharp
using var httpClient = new HttpClient();
using var formData = new MultipartFormDataContent();
var imageContent = new ByteArrayContent(File.ReadAllBytes("图片路径.jpg"));
imageContent.Headers.ContentType = new MediaTypeHeaderValue("image/jpeg");
formData.Add(imageContent, "image", "capture.jpg");
var resp = await httpClient.PostAsync(
    "https://stopper-trimmer-tavern.ngrok-free.dev/detect", formData);
var bytes = await resp.Content.ReadAsByteArrayAsync();  // 画框图片字节
```

### 方式二：纯二进制（raw）

适用于从内存直接获取图片的场景，如摄像头抓拍。

**curl：**

```bash
curl -s -o /tmp/out_raw.jpg -w "HTTP %{http_code} | %{content_type}\n" \
  -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect/raw \
  -H "Content-Type: image/jpeg" \
  --data-binary @图片路径.jpg
```

**Python（从摄像头内存数据直接发）：**

```python
import requests

image_data = camera_sdk.get_frame()  # bytes，从摄像头内存直接拿

resp = requests.post(
    "https://stopper-trimmer-tavern.ngrok-free.dev/detect/raw",
    data=image_data,
    headers={"Content-Type": "image/jpeg"},
    timeout=30,
)
if resp.status_code == 200:
    with open("result.jpg", "wb") as f:
        f.write(resp.content)
else:
    print(resp.json())
```

## 三、视频检测

对视频**逐帧检测并画框**，返回 MP4 视频。

**限制：**
- 接受任意尺寸/时长，**按原分辨率处理返回**（不缩放）
- 上限：文件 > 500MB 或时长 > 300 秒返回说明

**curl（保存结果到 /tmp/out.mp4）：**

```bash
curl -s -o /tmp/out.mp4 -w "HTTP %{http_code} | %{content_type} | 耗时 %{time_total}s\n" \
  -m 120 \
  -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect/video \
  -F "video=@视频路径.mp4"
```

**Python：**

```python
import requests

resp = requests.post(
    "https://stopper-trimmer-tavern.ngrok-free.dev/detect/video",
    files={"video": open("视频路径.mp4", "rb")},
    timeout=120,
)
if resp.status_code == 200:
    with open("result.mp4", "wb") as f:
        f.write(resp.content)
    print("已保存 result.mp4")
else:
    print(resp.json())
```

## 四、成功响应说明

| 接口 | 成功 HTTP 状态 | Content-Type | Body 内容 |
|------|---------------|--------------|----------|
| `/detect` | 200 | `image/jpeg` | 画框图片字节，未检测到目标时返回原图 |
| `/detect/raw` | 200 | `image/jpeg` | 画框图片字节，未检测到目标时返回原图 |
| `/detect/video` | 200 | `video/mp4` | 逐帧画框的 mp4 视频字节 |

调用方只需把响应 body 直接存成 `.jpg` / `.mp4` 文件即可。

### 📌 输出文件名由调用方自定义

**服务端返回的是图片/视频的二进制字节，文件名完全由调用方决定**，没有任何限制：

```bash
# 名字随便起，想叫什么都行：
curl -s -o ~/Desktop/我的检测结果.jpg ...   # 图像结果
curl -s -o /tmp/boar_result.jpg ...          # 换个名字/路径
curl -s -o output_video_001.mp4 ...          # 视频结果
```

- 不需要跟上传的文件名一致，扩展名也可以自定（如把视频存成 `.bin` 也行，内容还是 mp4）
- 图像内容始终是 JPEG、视频始终是 MP4（由 `Content-Type` 决定），**保存名只是你本地起的别名**

**成功响应头（返回原始数据大小信息）：**

| 响应头 | 说明 | 图像 | 视频 |
|--------|------|:---:|:---:|
| `X-Original-Width` | 原始宽度（像素） | ✅ | ✅ |
| `X-Original-Height` | 原始高度（像素） | ✅ | ✅ |
| `X-Original-Duration` | 原始时长（秒） | — | ✅ |
| `X-Original-Size` | 原始文件大小（字节） | — | ✅ |

示例：`curl -D -` 查看响应头时能看到 `x-original-width: 4000`、`x-original-height: 3000`。输出图片/视频尺寸与原始输入一致（不缩放）。

## 五、错误响应及处理

**错误时返回 HTTP 4xx/5xx + JSON**（不再用 HTTP 200 包一层）：

```json
{
  "code": 40001,
  "message": "图片过大（原始尺寸 9000×6000，原始数据大小 0.8MB），长边超过 8192px，请先压缩",
  "data": null
}
```

| HTTP 状态 | code | 含义 | 处理方法 |
|----------|------|------|---------|
| 400 | `40001` | 参数错误：图片/视频格式不支持、尺寸过大、时长超限、缺字段 | 按 message 提示修正 |
| 500 | `50001` | 模型推理/处理异常 | 稍后重试，持续失败请联系服务方 |

常见错误 message：
- `不支持的图片格式，仅支持 JPEG/PNG/BMP`
- `图片过大（原始尺寸 9000×6000，原始数据大小 0.8MB），长边超过 8192px，请先压缩`
- `请求中缺少 image 字段`
- `视频时长 45.0 秒超过处理上限 300 秒（原始时长 45.0s，原始数据大小 12.0MB）`
- `无法读取视频，请确认视频格式为 mp4/avi/mov`

## 六、快速验证脚本

在测试机上新建 `test_boar_public.py`：

```python
"""公网接口快速验证脚本（新版：返回画框图片/视频）"""
import os
import requests

BASE_URL = "https://stopper-trimmer-tavern.ngrok-free.dev"
IMAGE_PATH = "test.jpg"       # 替换为你的图片路径（任意尺寸）
VIDEO_PATH = "test.mp4"       # 替换为你的视频路径（任意尺寸/时长）


def test_health():
    resp = requests.get(f"{BASE_URL}/health", timeout=10)
    data = resp.json()
    print(f"[健康检查] status={data['status']}, device={data['device']}")
    return data["status"] == "ok"


def test_detect_multipart():
    with open(IMAGE_PATH, "rb") as f:
        resp = requests.post(f"{BASE_URL}/detect", files={"image": f}, timeout=30)
    ok = resp.status_code == 200 and resp.headers["Content-Type"] == "image/jpeg"
    if ok:
        with open("result_multipart.jpg", "wb") as f:
            f.write(resp.content)
    print(f"[multipart] {'✅ 200 画框图片' if ok else '❌ ' + str(resp.status_code) + ' ' + resp.text}")
    return ok


def test_detect_raw():
    with open(IMAGE_PATH, "rb") as f:
        resp = requests.post(
            f"{BASE_URL}/detect/raw",
            data=f.read(),
            headers={"Content-Type": "image/jpeg"},
            timeout=30,
        )
    ok = resp.status_code == 200 and resp.headers["Content-Type"] == "image/jpeg"
    if ok:
        with open("result_raw.jpg", "wb") as f:
            f.write(resp.content)
    print(f"[raw]       {'✅ 200 画框图片' if ok else '❌ ' + str(resp.status_code) + ' ' + resp.text}")
    return ok


def test_detect_video():
    if not os.path.exists(VIDEO_PATH):
        print("[video]    ⏭ 跳过（未提供视频）")
        return True
    with open(VIDEO_PATH, "rb") as f:
        resp = requests.post(f"{BASE_URL}/detect/video", files={"video": f}, timeout=120)
    ok = resp.status_code == 200 and resp.headers["Content-Type"] == "video/mp4"
    if ok:
        with open("result_video.mp4", "wb") as f:
            f.write(resp.content)
    print(f"[video]     {'✅ 200 画框视频' if ok else '❌ ' + str(resp.status_code) + ' ' + resp.text}")
    return ok


if __name__ == "__main__":
    print("=" * 40)
    print("野猪检测服务 · 公网接口测试")
    print("=" * 40)

    if not test_health():
        print("❌ 服务不可达")
        exit(1)
    print("✅ 服务可达")

    test_detect_multipart()
    test_detect_raw()
    test_detect_video()
```

运行：

```bash
python3 test_boar_public.py
```
