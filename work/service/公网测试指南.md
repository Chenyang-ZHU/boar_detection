# 公网接口测试方法

> 服务地址：`https://stopper-trimmer-tavern.ngrok-free.dev`（该账号绑定的固定域名，长期有效）

---

## 部署拓扑（2026-08 起）

```
公网客户端
   │  https
   ▼
ngrok 边缘节点（亚太 region=ap）
   │
ngrok agent ──▶ 192.168.1.55:5000  （Jetson，系统服务）
```

- **Jetson**（192.168.1.55，Ubuntu 22.04 / aarch64 / JetPack 6.2）上运行两个 systemd 服务，均开机自启：
  - `boar_detection.service` — 野猪检测服务（venv python app.py，监听 5000，CUDA 推理）
  - `ngrok.service` — 公网隧道（`ngrok http 127.0.0.1:5000 --region=ap`）
- 隧道地址为此账号固定域名，重启不变化
- 注意：ngrok **必须用 `--region=ap`**，默认 us 节点从国内访问会频繁断线（ERR_NGROK_3004/3200）

### ⚠️ ngrok 免费版使用限制（务必注意）

ngrok 免费版**对单次请求大小没有限制**（图片/视频随便传），但卡在**月度总量**，超限后连接会失败：

| 限制项 | 免费版额度 |
|--------|-----------|
| **月度带宽（最关键）** | **1 GB / 月** |
| HTTP 请求数 | 20,000 / 月 |
| 请求速率 | 4,000 次 / 分 |
| 在线端点 | 最多 3 个 |

**使用建议：**
- ✅ 公网**只用于测试验证**：传小图（几 MB）、短视频完全没问题
- ⚠️ **别用公网传大视频/大批量数据**：一次 500MB 视频上传就消耗掉月度额度一半；累计超 1GB 后连接直接失败
- 💡 大批量、大体积的检测走**局域网直连** `http://192.168.1.55:5000`（不限流量、更快）

> 补充：ngrok 免费版在**浏览器**里访问会弹"免费版提示页"，但 curl / Python 等**非浏览器客户端不受影响**。

## 接口一览

| 接口 | 方法 | 请求 | 成功响应 |
|------|------|------|---------|
| `/detect` | POST | multipart，字段 `image` | **检测坐标 JSON** |
| `/detect/raw` | POST | 纯二进制，`Content-Type: image/*` | **检测坐标 JSON** |
| `/detect/video/coords` | POST | multipart，字段 `video` | **逐帧检测坐标 JSON** |
| `/detect/video` | POST | multipart，字段 `video` | **画框 MP4 视频** |
| `/health` | GET | 无 | JSON 健康状态 |

> **所有响应统一 HTTP 200**，以 `code` 判断业务状态（0=成功）。图像/视频坐标走 JSON，画框视频走二进制 MP4。

## 二、图像检测（返回坐标）

返回**检测坐标 JSON**（归一化 bbox），支持 JPEG/PNG/BMP，接受任意尺寸（长边 > 8192px 或 > 50MB 返回说明）。

### multipart 方式

```bash
curl -s -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect \
  -F "image=@图片路径.jpg"
```

```python
import requests
resp = requests.post(
    "https://stopper-trimmer-tavern.ngrok-free.dev/detect",
    files={"image": open("图片路径.jpg", "rb")},
    timeout=30,
)
data = resp.json()
if data["code"] == 0:
    for d in data["data"]["detections"]:
        print(d["class"], d["confidence"], d["bbox"])
```

### 纯二进制方式

```bash
curl -s -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect/raw \
  -H "Content-Type: image/jpeg" \
  --data-binary @图片路径.jpg
```

### 成功响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "detections": [
      {"class": "boar", "class_id": 0, "confidence": 0.9355,
       "bbox": {"x1": 0.4308, "y1": 0.3639, "x2": 0.5637, "y2": 0.4587}}
    ],
    "image_width": 640,
    "image_height": 640,
    "inference_time_ms": 148.06
  }
}
```

## 三、视频检测（两种接口）

### 方式一：`/detect/video/coords` — 返回逐帧坐标 JSON

```bash
curl -s -m 120 -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect/video/coords \
  -F "video=@视频路径.mp4"
```

```python
import requests
resp = requests.post(
    "https://stopper-trimmer-tavern.ngrok-free.dev/detect/video/coords",
    files={"video": open("视频路径.mp4", "rb")},
    timeout=120,
)
data = resp.json()
if data["code"] == 0:
    print(data["data"]["frame_count"], "帧")
    for f in data["data"]["frames"]:
        if f["detections"]:
            print(f"帧{f['index']} @{f['timestamp_ms']}ms: {len(f['detections'])} 个目标")
```

      {"index": 0, "timestamp_ms": 0.0,

### 方式二：`/detect/video` — 返回画框 MP4

```bash
# 结果保存到 ~/Desktop/out.mp4，文件名由调用方自定义
curl -s -o ~/Desktop/out.mp4 -w "HTTP %{http_code} | %{content_type} | 耗时 %{time_total}s\n" \
  -m 120 \
  -X POST https://stopper-trimmer-tavern.ngrok-free.dev/detect/video \
  -F "video=@视频路径.mp4"
```

```python
resp = requests.post(
    "https://stopper-trimmer-tavern.ngrok-free.dev/detect/video",
    files={"video": open("视频路径.mp4", "rb")},
    timeout=120,
)
if resp.headers["Content-Type"] == "video/mp4":   # 成功 = 二进制视频
    with open("result.mp4", "wb") as f:
        f.write(resp.content)
    print("已保存 result.mp4")
else:                                              # 失败 = JSON
    print(resp.json())
```

**成功响应头（返回原始数据大小信息）：**

| 响应头 | 说明 |
|--------|------|
| `X-Original-Width` | 原始帧宽（像素） |
| `X-Original-Height` | 原始帧高（像素） |
| `X-Original-Duration` | 原始时长（秒） |
| `X-Original-Size` | 原始文件大小（字节） |

## 四、错误响应（HTTP 200 + code）

**所有错误都返回 HTTP 200**，以 `code` 区分：

```json
{ "code": 40001, "message": "图片过大（原始尺寸 9000×6000，原始数据大小 0.8MB），长边超过 8192px，请先压缩", "data": null }
```

| code | 含义 | 处理方法 |
|------|------|---------|
| `0` | 成功 | — |
| `40001` | 参数错误：格式不支持、尺寸/大小超限、时长超限、缺字段 | 按 message 提示修正 |
| `429001` | **服务繁忙**：同时处理请求数已达上限 | **退避重试**（3s+），不要立刻重发 |
| `50001` | 模型推理/处理异常 | 稍后重试，持续失败请联系服务方 |
| `50002` | 处理超时：单请求超过服务端时长上限 | 缩短视频/稍后重试 |

> 调用方应**始终解析 JSON 的 `code` 字段**判断成败，不要依赖 HTTP 状态码（都是 200）。
> 阻塞式调用方：收到 `429001` 退避重试；图片超时 30s、视频超时 180s；超时断开后服务端会中止处理，可放心重发。

## 五、快速验证脚本

新建 `test_boar_public.py`：

```python
"""公网接口快速验证脚本（坐标 + 画框视频）"""
import os
import requests

BASE_URL = "https://stopper-trimmer-tavern.ngrok-free.dev"
IMAGE_PATH = "test.jpg"   # 任意尺寸图片
VIDEO_PATH = "test.mp4"   # 任意尺寸/时长视频


def test_health():
    data = requests.get(f"{BASE_URL}/health", timeout=10).json()
    print(f"[健康检查] status={data['status']}, device={data['device']}")
    return data["status"] == "ok"


def test_detect_multipart():
    with open(IMAGE_PATH, "rb") as f:
        data = requests.post(f"{BASE_URL}/detect", files={"image": f}, timeout=30).json()
    ok = data["code"] == 0
    print(f"[multipart] {'✅ code=0, ' + str(len(data['data']['detections'])) + ' 个目标' if ok else '❌ ' + data['message']}")
    return ok


def test_detect_raw():
    with open(IMAGE_PATH, "rb") as f:
        data = requests.post(
            f"{BASE_URL}/detect/raw",
            data=f.read(),
            headers={"Content-Type": "image/jpeg"},
            timeout=30,
        ).json()
    ok = data["code"] == 0
    print(f"[raw]       {'✅ code=0, ' + str(len(data['data']['detections'])) + ' 个目标' if ok else '❌ ' + data['message']}")
    return ok


def test_video_coords():
    if not os.path.exists(VIDEO_PATH):
        print("[video坐标] ⏭ 跳过（未提供视频）")
        return True
    with open(VIDEO_PATH, "rb") as f:
        data = requests.post(
            f"{BASE_URL}/detect/video/coords", files={"video": f}, timeout=120
        ).json()
    ok = data["code"] == 0
    if ok:
        frames = data["data"]["frame_count"]
        hit = sum(1 for f in data["data"]["frames"] if f["detections"])
        print(f"[video坐标] ✅ code=0, {frames} 帧, {hit} 帧有目标")
    else:
        print(f"[video坐标] ❌ {data['message']}")
    return ok


def test_video_file():
    if not os.path.exists(VIDEO_PATH):
        print("[画框视频] ⏭ 跳过（未提供视频）")
        return True
    with open(VIDEO_PATH, "rb") as f:
        resp = requests.post(
            f"{BASE_URL}/detect/video", files={"video": f}, timeout=120
        )
    ok = resp.headers["Content-Type"] == "video/mp4"
    if ok:
        with open("result_video.mp4", "wb") as f:
            f.write(resp.content)
    print(f"[画框视频] {'✅ 200 画框视频' if ok else '❌ ' + resp.text}")
    return ok


if __name__ == "__main__":
    print("=" * 40)
    print("野猪检测服务 · 公网接口测试")
    print("=" * 40)

    if not test_health():
        print("❌ 服务不可达")
        exit(1)
    print("✅ 服务可达")

    test_detect_multipart()
    test_detect_raw()
    test_video_coords()
    test_video_file()
```

运行：

```bash
python3 test_boar_public.py
```
