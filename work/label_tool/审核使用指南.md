# 数据集审核使用指南

审核预标注结果，把认可的图并入 `work/merged`。

## 启动

```bash
cd work/label_tool && python label_tool.py
# 或 ./start.sh
```
浏览器打开 http://localhost:5000

## 本次要审核的数据集

| 数据集 | 内容 | 建议 |
|---|---|---|
| `frames` | 815 个视频抽出的帧（~5300 张） | 先审这个，量最大 |
| `pukou_img` | 浦口未标注的静态图（~1200 张） | 第二优先 |
| `yewei_img` | 野猪手工照片中未标注的（~5 张） | 很快 |
| `merged` | 已经审核通过并集成的图 | 只读，可看已集成的 |

> 置信度阈值已调到 **0.5**（原 0.25 误检太多）。这个模型整体过度自信，
> 高置信框里也可能混误检，审核时以**框是否贴住野猪**为准，别只看概率。
> 每个框右侧显示**置信度**：绿色 ≥0.5，红色 <0.5（手工新画的框显示 —）。

> 只有**模型检测到 ≥1 个框**的图才进了这些数据集；无检测的图被记在
> `work/prepare_dataset/negatives.csv`（以后需要负样本再补）。
> 源图损坏的记在 `work/prepare_dataset/unreadable.csv`。

## 操作

- 顶部下拉选择数据集 → 左侧列表选图 / 空格或 `d` 下一张
- **画框**：`D` 进入绘制模式，拖拽画矩形（类别固定 boar）
- **改框**：`S` 选择模式，点选框后拖动/缩放手柄
- **删框**：选中后按 `Delete`
- **保存**：`Ctrl+S`（改完即存，其实实时保存）
- **审核通过**：点绿色 `✅ 已审核 → merged`，当前图+标签并入 `work/merged` 并从本数据集移除
- **丢弃该图**：点删除按钮（整张不要，比如画面里没野猪、糊了）
- 图片右下角的 train/val/test 划分按钮只对 `merged` 生效，审核阶段不用管

## 审核原则

1. 框要尽量贴住野猪（红外照片边缘发白，宁大勿漏，但别框进大块背景）
2. 画面里**没野猪**的图 → 直接删除，不要通过
3. 一个图里**多只野猪**要分别框
4. 预标注框明显错的 → 拖正即可，不用重画
5. 拿不准的图跳过，最后回来再看

## 收尾

审核完（想审的都审了），跑：

```bash
python work/prepare_dataset/build_final.py    # 按 70/15/15 重写 merged 的 train/val/test.txt
```

然后就能用 `work/dataset.yaml` 训练了。
