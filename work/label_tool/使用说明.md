
# 野猪检测标注工具使用说明

由于 web 版工具遇到了一些问题，我们改用 **labelImg** —— 这是一个非常成熟的开源标注工具！

## 🚀 快速开始

### 方法一：使用启动脚本（推荐）

```bash
cd /home/zcy/.openclaw/workspace/boar_label_tool
./start_labelimg.sh
```

### 方法二：手动启动

#### 标注训练集：
```bash
labelImg \
  /home/zcy/Documents/project/boar_detection/work/dataset/train/images \
  /home/zcy/.openclaw/workspace/boar_label_tool/classes.txt \
  /home/zcy/Documents/project/boar_detection/work/dataset/train/labels
```

#### 标注验证集：
```bash
labelImg \
  /home/zcy/Documents/project/boar_detection/work/dataset/val/images \
  /home/zcy/.openclaw/workspace/boar_label_tool/classes.txt \
  /home/zcy/Documents/project/boar_detection/work/dataset/val/labels
```

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `w` | 创建矩形框 |
| `d` | 下一张图片 |
| `a` | 上一张图片 |
| `Ctrl + S` | 保存 |
| `Ctrl + d` | 复制当前标签和矩形框 |
| `Del` | 删除选中的矩形框 |
| `Ctrl + Mouse Wheel` | 放大/缩小 |

## 📝 使用步骤

1. **启动工具**：运行上面的命令
2. **确认格式**：在菜单中选择 `PascalVOC` -&gt; `YOLO`（确保是 YOLO 格式）
3. **开始标注**：
   - 按 `w` 键
   - 在野猪周围画矩形框
   - 输入标签：`boar`
4. **保存**：按 `Ctrl + S` 保存
5. **下一张**：按 `d` 继续标注下一张

## 📂 数据集结构

```
dataset/
├── train/
│   ├── images/   # 训练图片
│   └── labels/   # 训练标签（YOLO 格式）
└── val/
    ├── images/   # 验证图片
    └── labels/   # 验证标签（YOLO 格式）
```

## 💡 提示

- 你的数据集已经有自动标注的结果了，可以直接在这个基础上修改
- 画框时尽量紧贴野猪边缘
- 如果有多个野猪，每个都要单独画框
- 不确定的图片可以先跳过，稍后再回来
