
# 野猪检测标注工具

一个简单易用的 web 端标注工具，用于修正野猪检测数据集的标注。

## 功能特性

- 🖼️ 浏览训练集和验证集图片
- ✏️ 绘制新的标注框
- 👆 选择、查看和删除已有标注框
- 💾 实时保存修改
- ⌨️ 丰富的键盘快捷键

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动工具

```bash
python app.py
```

然后在浏览器中打开：`http://localhost:5000`

## 使用说明

### 基本操作

1. **选择数据集**：在顶部下拉菜单选择"训练集"或"验证集"
2. **浏览图片**：点击左侧图片列表或使用"上一张"/"下一张"按钮
3. **绘制标注框**：
   - 确保在"绘制模式"
   - 在图片上按住鼠标左键拖动绘制矩形
4. **选择标注框**：
   - 切换到"选择模式"
   - 点击标注框进行选择
   - 也可以在右侧列表中点击"选"按钮
5. **删除标注框**：
   - 选中要删除的框
   - 点击"删除选中"按钮或按 Delete 键
6. **保存**：点击"💾 保存"按钮或按 Ctrl+S

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| D | 绘制模式 |
| S | 选择模式 |
| Delete / Backspace | 删除选中的框 |
| A / ← | 上一张图片 |
| D / → | 下一张图片 |
| Ctrl + S | 保存标注 |

## 数据集格式

工具使用标准的 YOLO 数据集格式：

```
dataset/
├── train/
│   ├── images/
│   │   ├── img1.jpg
│   │   └── img2.jpg
│   └── labels/
│       ├── img1.txt
│       └── img2.txt
└── val/
    ├── images/
    └── labels/
```

标注文件格式（YOLO 格式）：
```
class_id x_center y_center width height
```

所有坐标都是归一化的（0-1 之间）。

## 配置

在 `app.py` 中修改 `DATASET_PATH` 变量来指定你的数据集路径：

```python
DATASET_PATH = Path("/path/to/your/dataset")
```
