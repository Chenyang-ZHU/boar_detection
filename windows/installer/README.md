# 野猪检测工具 · Windows 傻瓜安装包

给无电脑基础的甲方用的 Windows 版本安装包。**全程双击，无需敲任何命令。**

## 使用流程（三步，全双击）

| 步骤 | 谁来做 | 操作 |
|------|--------|------|
| ① 一键打包 | 技术员（有网络的 Windows PC） | 双击 **`一键打包.bat`**，等 10-15 分钟 |
| ② 安装到桌面 | 技术员或甲方 | 双击 **`安装到桌面.bat`** |
| ③ 使用 | 甲方 | 双击桌面「**野猪检测工具**」图标 |

## 功能

- 📷 检测单张图片（选图 → 自动标注 → 保存结果）
- 📁 批量检测图片文件夹
- 🎬 检测视频（逐帧分析 → 输出标注视频）
- 置信度阈值默认 0.25、IoU 0.45，可在界面调整

## 目录结构

```
windows/
├── boar_ui/                  # UI 源码（app.py / detector.py / model/best.onnx）
└── installer/                # 傻瓜安装包（本目录）
    ├── 一键打包.bat          # ← 技术员先运行这个：装 Python + 依赖 + 打 exe
    ├── 安装到桌面.bat        # ← 给桌面建快捷方式
    └── BoarDetector.exe      # ← 打包完成后生成（发给甲方就是这个文件）
```

## 给甲方的最终交付物

打包完成后，只需要 3 个东西：
1. `BoarDetector.exe`（或桌面快捷方式）
2. 安装说明.txt
3. （可选）`test.jpg` 测试图

甲方机器**不需要装 Python、不需要联网**——exe 已自带运行环境。

## 说明

- 打包机器需要联网（下载 Python + 依赖），目标机器不需要
- 产出的 `BoarDetector.exe` 约 50MB，单文件、免安装，双击即用
- 打包用清华镜像源，国内网络较快；失败会自动切换默认源
